# KTU Pulse

**A smarter, more accessible KTU student portal.**

KTU Pulse is a redesigned student portal concept for APJ Abdul Kalam Technological University (KTU), Kerala. It aims to make academic information easier to find through a responsive interface, prioritised notices, multilingual support, and student-friendly navigation.

## Features

* **Pulse Priority:** Organises notices into Action Required, Coming Up, and New Updates.
* **Home Dashboard:** Quick links, upcoming examinations, and latest notices.
* **Examination Portal:** Search and filter examination notices and schedules.
* **Results Page:** Semester-based result lookup with a demo results view.
* **Global Search:** Quickly find notices and examination information.
* **English and Malayalam:** Language switching for improved accessibility.
* **Ask Pulse:** A chatbot interface for portal navigation and common queries.
* **Notification Centre:** View notifications, unread counts, and read status.
* **Responsive Design:** Designed for mobile, tablet, and desktop screens.

## Getting Started

### Prerequisites

* Node.js (LTS recommended)
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

### Available Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

These commands depend on the scripts configured in `package.json`.

## What Makes KTU Pulse Different?

**Pulse Priority** helps students identify important announcements by grouping notices according to urgency and relevance. Combined with bilingual navigation, global search, and Ask Pulse, the project focuses on making the student experience simpler and more accessible.

## Data and Integrations

KTU Pulse is a portal redesign concept. Unless explicitly integrated and verified, examination information, notices, chatbot responses, and results use demo data. The project does not claim access to KTU's live systems or private student records.
